# Support

## Getting Help
For usage or setup questions, open a GitHub issue with:
- your environment (macOS version, chip, monitor setup)
- what you tried
- screenshots/log snippets if relevant

## Before Opening an Issue
1. Check [README.md](README.md)
2. Check [docs/README.md](docs/README.md)
3. Check known limitations in README

## Issue Types
- **Bug report**: unexpected behavior
- **Documentation issue**: inaccurate or unclear docs
- **Feature request**: proposed improvement with user scenario

## Response Expectations
This is an early-stage open-source project. Response times may vary.
