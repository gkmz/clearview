# Security Policy

## Supported Versions
At this stage, security and stability fixes are applied to the latest development line.

## Reporting a Vulnerability
If you discover a security issue, please do **not** open a public issue with exploit details.

Instead, report privately with:
- affected version/commit
- impact summary
- reproduction steps
- optional proof-of-concept (minimal)

Temporary reporting channel:
- Open a GitHub issue titled `Security: Private report requested` without details, and request a private contact path.

## Scope Notes
Current ClearView scope is local desktop functionality:
- no user accounts
- no cloud sync
- no remote telemetry

Even so, please report:
- privilege/permission misuse
- unsafe file or process handling
- shortcut/event handling vulnerabilities
