# ClearView Product Plan (0.1)

## 1. Positioning
ClearView is a macOS eye-care productivity utility focused on:
- lightweight reminder interactions,
- low interruption cost,
- visual comfort customization.

## 2. Target Users
1. Knowledge workers with long daily screen time.
2. Users who want eye-care reminders without heavy workflow disruption.
3. macOS users preferring menu bar tools.

## 3. Product Value
- **Health value**: encourages periodic breaks.
- **Efficiency value**: supports pause/resume/snooze for realistic work rhythms.
- **Experience value**: immersive but unobtrusive UI.
- **Reliability value**: local persistence keeps behavior predictable across restarts.

## 4. Scope Boundary

### In Scope (0.1)
- Reminder lifecycle with preparation and break countdown.
- Menu bar quick controls.
- Blue light filter presets.
- Global shortcut configuration.
- Local settings persistence.

### Out of Scope (0.1)
- Analytics/report dashboard.
- Context-aware auto pause strategies.
- Cloud sync or multi-device account system.

## 5. Operating Model (0.1)
PLG-first:
- Acquisition via developer/productivity communities.
- Activation through first successful reminder loop.
- Retention through low-friction controls (pause/resume/snooze).

## 6. Monetization Direction
- Phase 1 (0.1–0.2): free, validate retention.
- Phase 2 (0.3+): freemium trial with premium value on insights and advanced personalization.

## 7. Risks & Mitigations
1. **Substitution risk** (many timer tools)
   - Mitigation: differentiate via eye-care specific workflow quality.
2. **Retention risk**
   - Mitigation: optimize interruption quality and reminder trust.
3. **Compatibility risk**
   - Mitigation: define and maintain system/display test matrix.
4. **Trust/privacy risk**
   - Mitigation: local-first data model and explicit boundaries.

## 8. Milestones
- **0.1**: MVP stabilization and documentation standardization.
- **0.2**: usability enhancements and compatibility hardening.
- **0.3**: premium capability experiments.

## 9. Success Metrics (Suggested)
- D1 / D7 retention
- reminder completion rate
- snooze ratio
- settings customization rate
