# Contributing

Thanks for helping improve ClearView.

## Before You Start
- Search existing issues to avoid duplicates.
- Open an issue first for large changes.

## Local Setup
1. Open `ClearView.xcodeproj` in Xcode.
2. Select scheme `ClearView`.
3. Verify with `Product -> Build` (and `Product -> Test` if applicable).

## Pull Requests
- Keep PRs focused and small.
- Add or update docs when behavior changes.
- Keep critical logic documented with concise comments.
- Do not commit secrets or local environment files.
